# Reino Ajolote — media

Videos cortos del juego **Reino Ajolote** (Capacitor/Android), servidos por GitHub Pages
para no engordar la app. Se generan con `tools/gen-video.py` en el repo del juego.

| Archivo | Uso |
|---|---|
| `villainN_reveal.mp4` | Presentación del Oscuro N al desbloquearlo |
| `heroN_evo.mp4` | Ceremonia de evolución del héroe a la etapa N |

480×854, H.264, sin audio (el juego los reproduce en silencio y en bucle).
